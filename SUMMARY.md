### Step 1: Initialize Git (2 minutes)
```bash
cd c:\Users\richa\Downloads\public_html
git init
git add .
git commit -m "Initial commit: Vic Paradise Rental Car website"
```

### Step 2: Create GitHub Repo (1 minute)
1. Go to https://github.com/new
2. Create "vic-paradise-rental-car" repository
3. Push your code:
```bash
git remote add origin https://github.com/YOUR_USERNAME/vic-paradise-rental-car.git
git branch -M main
git push -u origin main
```

### Step 3: Deploy to Vercel (1 minute)
**Option A: Dashboard (EASIEST)**
1. Go to https://vercel.com
2. Click "Add New" → "Project"
3. Import your GitHub repo
4. Click "Deploy" 🎉

**Option B: CLI**
```bash
npm install -g vercel
vercel login
vercel --prod
```

**DONE! Your site is LIVE!** ✅
